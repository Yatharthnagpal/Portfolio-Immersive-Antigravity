# QA Rules

Before declaring the local build complete:

## Functional
- no runtime errors
- no hydration errors
- no broken routes
- no broken links
- no missing images
- navigation works
- project interactions work
- contact flow works

## Visual
- hero reads immediately
- motorcycle silhouette is believable
- face is naturally integrated
- text remains readable over 3D
- transitions are coherent
- HUD is subtle
- project environments feel distinct

## Performance
- inspect FPS on desktop
- inspect mobile performance
- check GPU/memory pressure
- avoid unnecessary re-renders
- lazy-load heavy scenes

## Accessibility
- keyboard navigation
- focus visibility
- semantic headings
- reduced motion
- readable contrast

Do not approve based only on a successful build.
