# Yatharth Nagpal — Immersive Portfolio / Antigravity

## Concept
**RIDE THE SYSTEM** — an immersive, cinematic developer portfolio built around an original modern-classic roadster inspired by the visual proportions and design language of a Hunter 350.

The motorcycle is the visual anchor. The road represents the journey. Each environment represents a part of Yatharth's engineering work.

## Local-first rule
This package is designed for **Antigravity / local IDE implementation first**.

Do not push to GitHub while implementing. Do not create branches. Do not create pull requests. Do not merge changes.

Workflow: Audit → Architecture → Prototype → Implement → Browser QA → Mobile QA → Performance QA → Owner approval → Git later.

## Identity
The rider represents Yatharth Nagpal. The helmet acts as a mask/framing device and Yatharth's real face is subtly visible behind/through the visor.

A real reference photo must be supplied by the owner. Never invent or substitute the face.
