# 3D Asset Specification

## Motorcycle
Create an original modern-classic roadster.

Reference characteristics:
- compact roadster proportions
- round headlamp
- compact tank
- exposed engine
- upright handlebars
- short exhaust
- compact seat
- roadster wheel proportions
- visible frame
- visible suspension

## Materials
Body: dark graphite / metallic finish.
Engine: brushed metal.
Rubber: matte.
Glass: smoked.
Headlamp: warm white.
Accent: restrained green.

## Rider
Helmeted rider with realistic anatomy and riding posture.

Helmet:
- dark graphite
- subtle metallic highlights
- smoked/partially transparent visor
- no brand logos

Face:
Use Yatharth reference behind visor. Natural integration through lighting and masking.

## Technical
Prefer GLB/GLTF if a high-quality asset is used. Compress geometry/textures. Use LOD where appropriate. Keep mobile fallback.

## Fallback
If full 3D rider/face integration becomes too expensive: use a 2.5D cinematic composition with depth and lighting. The experience matters more than forcing every element into full 3D.
