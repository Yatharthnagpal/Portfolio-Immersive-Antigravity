# Antigravity Workflow

## Phase 0 — Backup
Create a local backup/snapshot before substantial edits.

## Phase 1 — Audit
Inspect package.json, app routes, components, current 3D scene, styles, assets, project data and responsive behavior. Output an architecture report.

## Phase 2 — Plan
Create a dependency and component plan before implementation.

## Phase 3 — Visual prototype
Implement only road, motorcycle, rider silhouette, camera, HUD and scroll progress. Validate the core ride.

## Phase 4 — Identity
Integrate the supplied Yatharth face reference behind the helmet/visor.

## Phase 5 — Portfolio sections
Map existing content into Rider / Systems / Garage / Projects / Finish.

## Phase 6 — Project worlds
Implement each project environment incrementally.

## Phase 7 — Mobile
Create mobile-specific performance and camera behavior.

## Phase 8 — Performance
Measure, profile, optimize.

## Phase 9 — QA
Use `QA_CHECKLIST.md`.

## Phase 10 — Owner review
Stop. Do not Git push.

Only after explicit approval should Git operations happen.
