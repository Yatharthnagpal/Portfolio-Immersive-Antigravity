# Product Requirements Document

## Product
Yatharth Nagpal — Immersive 3D Portfolio

## Working title
RIDE THE SYSTEM

## Product objective
Transform the current developer portfolio into a memorable, premium, cinematic experience that still communicates professional information clearly.

## Target audience
- recruiters
- engineering managers
- technical founders
- clients
- collaborators
- developers

## Core promise
The visitor does not simply scroll through a portfolio; they ride through Yatharth's engineering journey.

## Primary experience
A modern-classic roadster carries the visitor through:
1. Rider / identity
2. Systems / technology
3. Garage / experience
4. Project Track
5. Finish / contact

## Hero
Black screen → system initialization → headlamp → helmet/rider reveal → subtle face reveal → Yatharth name → acceleration.

## Identity
Helmet is a mask/framing device. Yatharth's real face appears naturally behind/through the visor.

Use an owner-provided reference photograph. Never invent the identity.

## Sections

### 01 Rider
Name, title, profile, specialties, social links.

### 02 Systems
Technology organized as machine systems:
- Engine
- Intelligence
- Control
- Infrastructure

### 03 Garage
Experience and education presented as a cinematic technical log/timeline.

### 04 Projects
Projects become interactive environments rather than simple cards.

Suggested environments:
- MedAI Pro: medical/neural
- LegalAI: documents/RAG
- GNN Fraud Detection: graph network
- EcomGuard: transaction/fraud stream
- other verified portfolio projects as applicable

### 05 Finish
Motorcycle slows and the experience resolves into a strong contact CTA.

## Success criteria
A visitor should remember the experience and still understand:
- who Yatharth is
- what technologies he uses
- what projects he has built
- how to contact him

## Constraints
- Local-first development.
- No PR workflow.
- No Git operations until owner approval.
- No fabricated facts.
- No proprietary motorcycle branding/assets.
- 3D must not hide important content.
