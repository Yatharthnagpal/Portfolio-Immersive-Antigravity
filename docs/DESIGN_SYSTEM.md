# Design System

## Mood
Premium, technical, cinematic, understated.

## Materials
- brushed metal
- graphite
- matte rubber
- smoked glass
- translucent HUD glass

## UI
Thin borders. Soft blur. Small labels. Monospace telemetry. Large editorial headings.

## HUD
NY // RIDE
SYSTEM ONLINE
SECTOR 04 / PROJECTS
SPEED 128 KM/H
SCROLL // ACCELERATE

HUD should never dominate content.

## Spacing
Use generous whitespace around text and strong alignment. Do not fill empty space with random decoration.
