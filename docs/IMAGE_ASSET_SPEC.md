# Image Asset Specification

## Required owner asset
`assets/rider/yatharth-face-reference.jpg`

Recommended:
- high resolution
- front or 3/4 portrait
- neutral expression
- clear face
- no sunglasses
- no heavy filters
- good lighting

## Production assets
Possible derived assets:
- yatharth-face-cutout.webp
- yatharth-face-dark.webp
- yatharth-face-mask.webp

Keep the original reference outside public production assets unless explicitly needed.

## Website image categories

### Rider
Helmet portrait / rider silhouette / close-up.

### Environments
Night road, garage, technical tunnel, project-specific atmosphere.

### Projects
Only use project visuals that support verified project information.

### UI
HUD textures, grain, subtle scanline overlays.

## Asset rule
Do not use stock images as if they depict Yatharth. Do not invent project screenshots or metrics.
